**0.4 三个被推翻的设计决策**
- ❌ ai.generate native 手搓 CompletionRequest → 应走 auto-ai high-level API

- ❌ ChatSession 手搓历史回放 → 应由 auto-ai 提供"带历史的会话"抽象

- **auto-shell 侧**：新增 auto-ai-agent 依赖、AshCommandTool 桥（参考 auto-ai-cli/tools.rs）、SmartCommand 领域逻辑（command.at/executor/CLI）、前端集成（ChatSession 渲染/F3 预览）。
- 标注两侧的依赖关系和并行性。

**0.6 工作量修订**
- auto-ai 侧：约 3-4 周（链路补全 + provider + role）
- auto-shell 侧：从原 12-16 周降至约 6-8 周（不再自实现 harness）
