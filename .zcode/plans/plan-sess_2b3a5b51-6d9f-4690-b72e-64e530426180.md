## SmartCommand 领域逻辑 v1（纯 auto-shell，不加新 native）

### 范围（方案 1，已定）
落地 SmartCommand 的领域逻辑（command.at 加载/解析/executor/CLI），**零跨仓库改动**。body.ash 用现有能力：`$1/$2` 取参数（Plan 034 已支持）+ `system()`（已有 native）+ AutoLang 原生语法。AI 判断步骤由 executor 在 body 执行前后用 SmartCommandRole 调 Agent（不在 body.ash 内用 native）。

### 依据（已核实）
- `Shell::execute_script_content(content)`（shell.rs:2388）能跑 .ash 脚本 ✓
- `set_script_args(args)`（shell.rs:443）+ `$1/$2/$@/$#` 展开（shell.rs:2867）已支持 ✓
- SmartCommandRole + Agent + AshCommandTool 桥已就绪 ✓
- main.rs 手写 CLI 循环（while+match），可加 `smart` 子命令分支 ✓

### 设计（5 个新文件 + main.rs 改动）

#### 1. `smart_command/config.rs` — SmartCommandSpec + parse/serialize
照搬 029 §A.2-A.3 的 schema。command.at 格式：
```
command "git.finish-worktree" {
    description : "Finish a worktree: commit, push, remove branch"
    args        : ["target"]        // 位置参数名（文档用）
    body        : "git.finish-worktree.ash"   // body.ash 文件名（同目录）
}
```
- `SmartCommandSpec { name, description, args: Vec<String>, body: String }`
- 用 auto-lang 的 `.at` 配置解析器（auto_config.rs 已有解析能力），或最小自解析
- parse + serialize（测试往返）

#### 2. `smart_command/loader.rs` — 扫描 + 覆盖
搜索路径（优先级高→低，同名覆盖）：
1. `$CWD/smart/` — 项目本地
2. `~/.config/ash/smart/` — 用户全局
3. 内置（打包的，v1 可空）
每个目录扫 `*.at` 文件，解析为 Spec，按 name 去重（先找到的优先）。`load_all() -> Vec<SmartCommandSpec>`。

#### 3. `smart_command/executor.rs` — 执行 body.ash
`execute(spec, args, &mut shell) -> Result<String>`：
1. `shell.set_script_args(args)` —— $1/$2 注入
2. 找到 body 文件（spec 同目录的 `spec.body`）
3. `shell.execute_script_content(&body_content)` —— 跑 body.ash
4. 返回输出
body.ash 里用 `system("git add ...")` + AutoLang 逻辑（if/for）+ `$1` 取参。

#### 4. `smart_command/role.rs` — NLU 衔接（v1 薄封装）
`build_smart_role(spec) -> SmartCommandRole` —— 把 spec 的 description 渲染进 system prompt，allowed_tools 设为 spec 允许的命令。复用已完成的 SmartCommandRole。v1 先做骨架，真正的 Agent::run NLU 流程在后续（需 daemon），本次只提供构造方法。

#### 5. `smart_command/cli.rs` — `ash smart` 子命令
在 main.rs 的 match 里加 `"smart"` 分支，委托给 cli.rs：
- `ash smart list` —— 列出所有 SmartCommand
- `ash smart run <name> [args...]` —— 执行（executor）
- `ash smart "<自然语言>"` —— NLU 匹配 + 执行（v1 可先只支持 list/run，NL 留 stub）

#### 6. `smart_command.rs`（改） — 模块组织
把现有 `smart_command.rs`（只有 SmartCommandRole）改为 `smart_command/mod.rs`，加 config/loader/executor/role/cli 子模块。或保持单文件 + 新模块并列。倾向 mod.rs 组织。

#### 7. git.finish-worktree 实例（验证用）
`examples/smart/git.finish-worktree.at` + `git.finish-worktree.ash`（body：system("git ...") 序列）。
