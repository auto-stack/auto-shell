# Plan 031 M3: ExternalStream → 真流式 StreamSource

## 目标
把 `ExternalStream` 的输出从"先 `read_all()` 全量缓冲再进 pipeline"升级为"边读边 yield 的 `StreamSource`"，使 `take`/`filter` 等流式算子真正提前终止，不再为未使用的行分配内存。

## 技术方案

### 核心思路
`LazyNode::StreamSource` 骨架已存在且 `Iterator::next()` 已处理。只需把 `flush_dsl_ops!` 里 ExternalStream 的路径从 `into_dsl_input()`（全文缓冲）改为 `build_lazy_from_iter()`（边读边 yield）。

### 改动 1：`lazy.rs` — 抽 `wrap_ops` helper + 新增 `build_lazy_from_iter`（~30 行）

把 `build_lazy` 内部的 op-wrapping 循环抽成 `fn wrap_ops(node: LazyNode, ops: &[PipelineOp]) -> LazyNode`，然后：

```rust
pub fn build_lazy_from_iter(
    ops: &[PipelineOp],
    iter: impl Iterator<Item = Value> + Send + 'static,
) -> LazyNode {
    wrap_ops(LazyNode::StreamSource(Box::new(iter)), ops)
}
```

`build_lazy` 自身改为 `wrap_ops(LazyNode::from_vec(source_to_rows(source)), ops)`。

### 改动 2：`shell.rs` — `flush_dsl_ops!` 分流 ExternalStream（~25 行）

```rust
let pipeline = input_pipeline.take();
let is_external_stream = matches!(&pipeline, Some(AtomPipeline::ExternalStream(_)));

let result_val = if is_external_stream {
    let es = match pipeline.unwrap() { 
        AtomPipeline::ExternalStream(es) => es, _ => unreachable!() 
    };
    let iter = es.lines()
        .filter_map(|r| r.ok())        // 跳过 I/O 错误行
        .map(|line| Value::str(&line));
    build_lazy_from_iter(&ops, iter).collect()
} else {
    let source = match pipeline {
        Some(p) => p.into_dsl_input(),
        None => Value::Array(Array::new()),
    };
    build_lazy(&ops, source).collect()
};
```

**优化无条件**：不判断 ops 是否全是流式算子。SortBy/Aggregate 也会从 StreamSource 正确 drain（和从 Source drain 一样），无劣势。

### 改动 4：更新 M2.3 benchmark（~40 行）

给 `pipeline_bench.rs` 加 `filter|take 100 (stream)` 场景——用 `std::iter::from_fn` 模拟 ExternalStream 的懒迭代（不预先物化 10k 行），验证 `peak_lazy < peak_eager * 0.1`。

### 安全分析

- **子进程提前终止**：`take` 提前 drop `StreamSource` → drop `ExternalStream` → drop `BufReader<ChildStdout>` → 关闭 pipe → 子进程收到 EPIPE/SIGPIPE。与 Unix 管道早期终止语义一致。
- **后台线程不泄漏**：`exit_status` 用 `Arc`，后台线程持有独立引用，子进程退出后线程自然结束，Mutex 随 Arc 最后释放。
- **`Send` 约束**：`ExternalStream::lines()` 返回的迭代器包含 `BufReader<ChildStdout>`，ChildStdout 是 `Send` 的，满足 `StreamSource(Box<dyn Iterator + Send>)`。

## 不做的
- 不删 `into_dsl_input` 的 ExternalStream 分支（AtomPipeline::Stream 等其他路径仍需要，且可作为降级回退保留）
- 不把 `is_external_stream` 判断提升为 pub API（内联在 flush 宏里即可）
