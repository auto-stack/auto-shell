# ash — AutoShell Skill

## When to use ash
（3-5 个典型场景：查看代码文件、搜索代码库、处理结构化数据、shell 操作）

## Core concept: structured pipelines
（最重要的 ash 特性：`ls | grep ".rs" | select name`，命令间传结构化数据而非纯文本）

## Essential commands（15-20 个，每个含 1-2 个实用示例）

### Viewing files
- show（强调 show > cat，自动语法高亮，--as 强制格式，-p 交互分页）
- cat / head / tail（何时用它们而非 show）

### Searching
- grep（结构化输出 {file,line_number,text}，-r 递归，-l 仅文件名）
- find（-n 模式，-t 类型）

### File listing & info
- ls（-l 长格式，输出是结构化数组，可管道）
- wc（-l/-w/-c，管道感知）

### Data transformation（ash 的杀手锏）
- where / select / each / get（结构化过滤与字段提取）
- from_json / to_json / from_csv / to_csv（格式转换）
- sort（-w 字段排序，-n 数值）

### Text processing
- str-replace / str-trim / str-case
- cut / tr / uniq

## Agent integration patterns
（`ash -c "..." --json` 返回 JSON；`ash -s` 从 stdin 读脚本；安全沙箱）

## Full command reference

## Important notes

### 设计原则

1. **description 单行**（YAML 要求），写明触发场景和关键词
2. **示例驱动**：每个命令至少一个真实可用示例，而非参数罗列
3. **强调 ash 独有优势**：结构化管道、show 的语法高亮、--json agent 桥接
4. **标注陷阱**：open ≠ 读取、less 非脚本友好、head -n 限制
5. **渐进式**：高频命令详细写，低频命令简表
